# Secciones

Este archivo define todas las secciones, su orden, niveles de impacto y descripciones. El ID de
sección entre paréntesis es el prefijo de archivo usado para agrupar reglas.

---

## 1. Lifecycle (lifecycle)

**Impacto:** HIGH **Descripción:** Creación, actualización, preservación, versionado, frontmatter y
changelog de artefactos SDD.

## 2. Phase Gates (phase)

**Impacto:** HIGH **Descripción:** Phase gates, aprobación de implementación, evidencia apply/verify
y Strict TDD.

## 3. Apply Discipline (apply)

**Impacto:** HIGH **Descripción:** Reglas para implementar desde SDD tasks, reemplazar código y
limpiar deuda obsoleta.

## 4. Validation (language)

**Impacto:** MEDIUM **Descripción:** Política de idioma, comandos de validación y expectativas
operativas.
