# AutanaSoft SDD Lifecycle

Skill de lifecycle SDD para proyectos AutanaSoft.

## Estructura

```txt
autanasoft-sdd-lifecycle/
  SKILL.md
  AGENTS.md
  README.md
  references/
  rules/
```

## Objetivo

Mantener las reglas de lifecycle SDD separadas en archivos pequeños y mantenibles, en lugar de hacer
crecer un `SKILL.md` monolítico.

## Reglas

- `rules/lifecycle-living-artifacts.md`
- `rules/lifecycle-versioning-status.md`
- `rules/phase-approval-and-evidence.md`
- `rules/apply-cleanup-replaced-code.md`
- `rules/language-and-validation.md`

## Convención

`SKILL.md` debe actuar como índice operativo y resumen de reglas críticas. Las reglas detalladas
viven bajo `rules/`.
