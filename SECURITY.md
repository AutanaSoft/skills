# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| `main`  | Yes       |

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature to report security issues. Do not open a
public issue for a vulnerability, exposed credential, malicious skill instruction, or compromised
dependency.

Include the affected path, a description of the impact, reproduction steps, and any safe evidence
that helps us investigate. We will acknowledge the report through GitHub and coordinate remediation
before public disclosure.
